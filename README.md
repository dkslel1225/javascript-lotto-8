# javascript-lotto-precourse

## 구현할 기능 목록

미입력 체크, 공백 제거는 모든 인풋이 거쳐가는 함수로 만들어도 되겠다!

1. 로또 구입 금액 입력
   - 금액 입력 `inputMoney()`
     - 공백 제거, 양의 정수 체크
   - 로또 횟수 반환 `possibleTimes()`
   - 구입 금액은 1,000원 단위로 입력 받으며 1,000원으로 나누어 떨어지지 않는 경우 예외 처리한다.(1000원에 1회)
2. 로또 출력
   - 1~45사이의 랜덤 숫자 `getRandomNum()`
   - 미중복 `nonDuplicate()`
   - 오름차순 정렬 `sortAscending()`
   - 출력 `printLottoNumbers()`
3. 당첨 번호 입력
   1. 번호 6개를 입력받는다. `inputWinningNumbers()`
   2. (,로 구분) `parseWinnintNumbers()`
      1. 이후, 각 요소가 양의 정수인지 확인 `isPositiveInt()`
      2. 각 요소가 1~45사이의 숫자인지 확인 `isNumberInRange()`
   3. 보너스 번호를 입력받는다. `inputBonusNumber()`
      1. 양의 정수인지 확인 `Reuse isPositiveInt()`
4. 당첨 출력
   - 당첨 결과(`lottoResults()`): 입력 받은 당첨 번호와 내가 구매한 로또 번호를 비교해서 몇등 몇개인지 구한다.=>[3,4,5,6개 일치] 반환
   - 출력 형식
     - 3개 일치 (5,000원) - 1개
     - 4개 일치 (50,000원) - 0개
     - 5개 일치 (1,500,000원) - 0개
     - 5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
     - 6개 일치 (2,000,000,000원) - 0개
   - 수익률 계산(`rateOfReturn()`):
     - 수익률은 소수점 둘째 자리에서 반올림한다. (ex. 100.0%, 51.5%, 1,000,000.0%)
     - 수익률: 당첨금액 / 투자금액 \* 100
     - 반올림 메소드: 숫자.tofixed(2)
